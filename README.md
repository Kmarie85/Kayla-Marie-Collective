# Kayla Marie Collective Website

## Quick Setup (for new client sites)
1) Update:
- Title + meta description on every page
- Canonical domain
- OG image + favicon set

2) Replace brand assets:
- /Static/Images/* icons
- og-image.jpg

3) Update sitemap.xml URLs

4) Deploy:
- GitHub Pages → Custom domain
- DNS A records + CNAME www
- Enforce HTTPS

## Dev Notes
- No framework, plain HTML/CSS/JS
- Keep images in WebP
- Use defer on scripts

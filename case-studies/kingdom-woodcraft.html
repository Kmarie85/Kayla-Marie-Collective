The Problem

The business was relying on an outdated WordPress site that didn’t reflect the quality of their work and offered limited control over performance, structure, and tracking. The site needed to feel professional, load quickly, and be easy to maintain without plugin bloat.

The Solution

  • Rebuilt from scratch using semantic HTML/CSS/JS (no page builders)
  • Migrated off WordPress and deployed via GitHub Pages
  • Connected custom domain and handled DNS/propagation troubleshooting
  • Implemented SEO foundations: metadata, sitemap, robots.txt, canonical URLs
  • Installed GA4 correctly in the <head>
  • Added event tracking for key actions (calls + form submissions)
  • Optimized mobile spacing, navigation behavior, and gallery structure

The Result

  • Fast, clean site that matches the craftsmanship of the business
  • Fully owned infrastructure — no template lock-in
  • Mobile-friendly layout with clear navigation
  • Analytics and SEO in place for growth and measurement

Why This Approach

This build prioritized long-term ownership and performance over convenience — so the site can scale without breaking or needing a rebuild every year.
